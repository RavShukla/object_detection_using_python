# 🧠 Object Detection using OpenCV & SSD MobileNet

This project performs real-time and image-based **object detection** using OpenCV’s DNN module and a pre-trained **SSD MobileNet V3 model**, trained on the COCO dataset.

It detects 80 common objects like people, cars, bottles, etc., in both static images and live webcam feed.

## 🚀 Features

- 🖼️ Detects objects in images and real-time webcam feed
- 📦 Uses SSD MobileNet V3 trained on COCO dataset
- 🧠 Built with OpenCV DNN module
- 🖍️ Displays bounding boxes with class names & confidence
- 💾 Saves the annotated image as `output_detected.png`
- 📷 Webcam support with live object detection

# 🚀 Object Detection using YOLOv8 and OpenCV

This project demonstrates **real-time object detection** using the **YOLOv8 (You Only Look Once)** model integrated with **OpenCV**.  
It can detect multiple objects in images or live webcam feeds with high accuracy and speed.

---

## 🧠 Features

- 🎯 High-accuracy object detection using YOLOv8
- 💻 Real-time detection via webcam or camera feed
- 🖼️ Support for image input and live video
- ⚡ Optimized inference speed with Ultralytics YOLO library
- 🧩 Easy to modify and extend
